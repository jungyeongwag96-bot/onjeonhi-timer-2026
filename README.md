# 온전히 · 타이머 v2 (HTML / CSS / JavaScript)

기존 ChatGPT Sites를 사용하지 않는 독립형 PWA입니다. 보라/형광노랑 디자인, 인터벌, 스톱워치, 합성 알림음, 라운드 음성, 템플릿을 포함합니다.

## 실행
- `index.html`을 더블 클릭하여 기본 화면 확인
- PWA 기능 테스트: VS Code Live Server 또는 터미널에서 `npx serve .` 후 localhost 접속 (Node 설치된 경우)
- Python 불필요. 정적 파일로 Cloudflare Pages에 배포 가능.

## GitHub에서 업데이트
1. ZIP 압축을 풉니다.
2. `onjeonhi-timer-2026` GitHub 저장소에서 **Add file → Upload files**를 클릭합니다.
3. 압축 해제한 `onjeonhi-timer` 폴더 **내부의 파일과 assets 폴더**를 선택합니다. 파일을 저장소 루트에 업로드하세요.
4. 같은 이름의 기존 파일을 대체하는 변경을 확인하고 **Commit changes**를 누릅니다.
5. Cloudflare Pages에서 연결된 main 브랜치의 새 배포가 완료되면 새로고침합니다. 예전 디자인이 보이면 강력 새로고침(Ctrl+Shift+R) 또는 사이트 데이터 삭제 후 다시 접속해 보세요.

## 테스트
- 시작/일시정지/계속/초기화, 시간 1초/라운드 2회 입력 후 자동 전환 확인
- 소리 테스트는 사용자 클릭 뒤에 실행; 휴대폰 무음 모드 및 브라우저 음성 엔진에 따라 다를 수 있습니다.
- 템플릿 저장 후 새로고침, 스톱워치 랩 및 CSV 내보내기
- 휴대폰 가로 화면에서 숫자와 안내문 겹침 여부
- PWA 오프라인 사용은 HTTPS에서 한번 접속한 뒤 네트워크 차단하여 확인

## 제약
- 이전 Sites의 원본 소스에 접근하지 못해 *픽셀 단위 복제*가 아닌 요구사항 기반 재구현입니다.
- 벨/휘슬/나팔은 실제 음원 파일이 아닌 브라우저 합성음입니다.
- 템플릿은 현재 기기의 로컬 저장소에만 저장되며, 로그인 및 클라우드 동기화·광고·결제 기능은 없습니다.
