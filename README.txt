온전히 타이머 - 홈 화면 설치 지원 버전

1. ZIP 압축 해제.
2. GitHub onjeonhi-timer-2026 저장소의 최상위 경로에 index.html, manifest.webmanifest, service-worker.js, assets 폴더를 업로드하고 변경 사항을 커밋합니다. 기존 파일은 동일 경로에 덮어써야 합니다.
3. Cloudflare Pages 배포 성공 후 https://onjeonhi-timer-2026.pages.dev/ 에 접속합니다.
4. Android Chrome: 점 세 개 메뉴 > 앱 설치 또는 홈 화면에 추가. Samsung Internet: 메뉴(≡) > 현재 페이지 추가 > 홈 화면.
5. iPhone Safari: 공유 버튼 > 홈 화면에 추가 > 추가.
6. 설치를 완료하면 휴대폰 홈 화면의 '온전히 타이머' 아이콘으로 실행할 수 있습니다.
7. 오프라인: 온라인에서 한 번 실행하여 파일이 캐시에 저장된 뒤 비행기 모드로 다시 실행해 확인하세요.

주의: 브라우저별 설치 UI와 기준이 다릅니다. 192/512 PNG 아이콘, Web App Manifest, Service Worker를 포함했습니다. 설치 메뉴가 안 보이면 브라우저를 바꾸거나 업데이트하고, 캐시를 삭제한 뒤 새로고침하세요. 앱의 음성과 소리는 백그라운드에서 제한될 수 있습니다.
